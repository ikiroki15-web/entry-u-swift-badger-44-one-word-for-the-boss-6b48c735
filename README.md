make.fun bounty entry: **One Word for the Boss**.

`main.ts` writes exactly one word describing the boss to `/output/entry.txt`:

> **Ghost** — the boss who is never actually there, yet somehow haunts
> every meeting, every inbox, every shift.

Run it with Node 22:

```sh
node main.ts
```

It respects `MAKEFUN_OUTPUT_DIR` (default `/output`).
